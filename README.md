# TextCharEditor - 文字位置調整プラグイン
# v3.0(2026/08/28)への更新は必須です!!!
テキストオブジェクト(個別オブジェクトON)の各文字を個別に移動・拡大縮小・回転できるプラグインです。

## 使い方

1. `TextCharEditor.aux2` をインストール
   - https://github.com/kanade-ak/TextCharEditor/releases/tag/v3.0 からTextCharEditor.aux2をDLしてください
   - aviutl2 のプレビュー画面へ DLL をドラッグ＆ドロップ、または
     `data\Plugin` フォルダへコピーして起動
3. テキストオブジェクトを作成し、テキストの設定で **「個別オブジェクト」をON**
4. 同じテキストオブジェクトにフィルタ効果 **「文字位置調整」を追加**
5. 「TextCharEditorWindow」を開く(表示 → TextCharEditorWindow)
6. 各文字を操作
   - **空白をドラッグ / Ctrl+ホイール** : キャンバス移動 / ズーム
   - **ホイール** : 文字の拡大縮小
   - **上の丸印をドラッグ** : 回転
   - **角ハンドルをドラッグ** : 通常はドラッグ開始時の縦横比を維持。Shiftは横倍率を固定して縦だけ変更、Ctrlは縦倍率を固定して横だけ変更、Shift+Ctrlは縦横を個別に変更する自由変形
   - **ダブルクリック** : その文字だけリセット
   - **選択中の文字を右クリック** : その文字のフォント変更UI、またはその文字を対象に文字装飾(手書き)を開く
   - **選択文字とは別の文字を右クリック** : 右クリックした文字を基準に位置・形を合わせる
   - **キー設定** : 操作項目をダブルクリックし、次に押したキーをショートカットとして保存。方向固定キーも変更可能
   - **ショートカットキーを無効化** : 方向固定ドラッグ・Ctrl+ホイール・戻す・進めるを除くショートカットを停止
   - **Ctrl+Z / Ctrl+Y** : 配置・拡大縮小・回転の履歴を1つ戻す / 1つ進める
   - **文字装飾(手書き)** : ペン描画・消しゴム・スポイト・文字ごとに独立した戻す/進める・全消去・PNG書き出し・PNG読み込み
   - **PNG読み込み** : 画像中心に対象文字があるものとして、画像をリサイズせず元の幅・高さのまま対象文字の中心へ配置します
   - **PNG書き出し範囲** : `文字の大きさ`、`文字の大きさ+50%余白`、`全テキスト範囲`、`全テキスト範囲+50%余白`から選択でき、余白は取得範囲の縦横を1.5倍にし、追加部分を透明にします
   - **全リセット** : 変形・手書き装飾・読み込んだPNGを全てリセット
   - **フォント変更UI** : フォント名検索、選択一覧、表示/非表示管理、使用履歴から文字単体へ適用します。表示管理の「全選択」は全フォント、「Windows標準フォントのみON/OFFにする」は おそらく標準フォントであろうものを非表示にします
   - **フォントプレビュー** : 「プレビュー」をONにすると、一覧を各フォント自身で `フォント名 : 選択文字` の形式で表示されます
   - **文字対応フォントの自動抽出** : フォント選択一覧には、指定文字のグリフを実際に持つフォントだけを表示します
   - **使用したフォント履歴** : 適用したフォントを新しい順に保持します。履歴を右クリックするとピン留め/解除も可能です

## 色々な事
   - バグ等あると思いますのであったらお知らせください
   - 文字装飾(手書き)に関してはフォント側のライセンス等々に気を付けてお使いください
   - 機能追加予定あります。一応互換性保つ予定ですが、もしかしたら破壊的変更を加える可能性があります。
   - ショートカットキーと文字装飾(手書き)はBeta版だと思ってください。安定しないかも...

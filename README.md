# TextCharEditor - 個別オブジェクト文字エディタ

テキストオブジェクト(個別オブジェクトON)の各文字を個別に移動・拡大縮小・回転できるプラグインです。

## 使い方

1. `TextCharEditor.aux2` をインストール
   - aviutl2 のプレビュー画面へ DLL をドラッグ＆ドロップ、または
     `data\Plugin` フォルダへコピーして起動
2. テキストオブジェクトを作成し、テキストの設定で **「個別オブジェクト」をON**
3. 同じテキストオブジェクトにフィルタ効果 **「文字位置調整」を追加**
4. 本プラグインのウィンドウ「文字エディタ」を開く(ウィンドウ → 文字エディタ)
5. 各文字を操作
   - **空白をドラッグ / Ctrl+ホイール** : キャンバス移動 / ズーム
   - **ホイール** : 文字の拡大縮小
   - **上の丸印をドラッグ** : 回転
   - **角ハンドルをドラッグ** : X/Y方向の拡大縮小
   - **ダブルクリック** : その文字だけリセット
   - 「全リセット」ボタン : 全文字リセット
